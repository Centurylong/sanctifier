# Dead contract error variants (`SANCT_DEAD_CONTRACTERROR_VARIANT`)

This advisory detector flags a variant declared in a `#[contracterror]` enum
that has no source-local reference. It does not prove that a *public* ABI variant
is unused across a workspace or by downstream consumers. Review external call
sites before deleting a variant or changing stable numeric discriminants.

```rust
#[contracterror]
#[repr(u32)]
pub enum Error {
    InvalidAmount = 1,
    RemovedPath = 2, // advisory if not referenced in scanned source
}

fn validate() -> Result<(), Error> { Err(Error::InvalidAmount) }
```

The detector recognizes qualified paths (`Error::InvalidAmount`), references
inside an `impl Error` via `Self::InvalidAmount`, and imported names. It treats
matching identifiers in macro bodies/invocations conservatively as used, rather
than issuing potentially incorrect deletion advice about code generated by a
macro. It emits a warning, not an automatic patch or removal operation.

**Limitations:** File-local static analysis cannot determine whether an API
variant is constructed in another module/crate, indirectly through reflection,
or by a procedural macro not naming the variant in its input tokens. Treat
findings as a review queue, not proof of dead ABI members.
